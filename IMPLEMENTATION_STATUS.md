```css
  outline: 2px solid var(--accent);

}

a:focus-visible, [role="link"]:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}

input:focus-visible, textarea:focus-visible, select:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 1px;
}

[tabindex]:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

**Key Decisions:**
- Global `:focus-visible` rule provides baseline for all elements
- 2px outline width: visible without being overwhelming
- 2px offset: creates breathing room around elements
- `var(--accent)` color: auto-adjusts across themes
- Form inputs use 1px offset (working with existing box-shadow)

## Design Specifications

### Focus Ring Styling

**Universal Rule:**
```css
:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

**Visual Characteristics:**
- **Color:** Green (#247420 light, #3A9A34 dark)
- **Width:** 2px solid outline
- **Offset:** 2px from element edge
- **Shape:** Rectangle (follows element shape)

**Theme Support:**
- Light theme: Green on white (9.8:1 contrast)
- Dark theme: Bright green on dark (8.2:1 contrast)
- Auto theme: Responds to system preference
