flatspace v1.0.17 dual-mode build: when flatspace.config.mjs exists in cwd, runs THEME MODE (calls theme.render(ctx) returning Array<{path,html}>, writes to outDir default 'docs', reads YAML from contentDir default 'content'). Absent config -> legacy bun build mode. Theme contract: ctx.read('pages').docs, ctx.readGlobal(slug), ctx.writeFile(rel, data). CI builds via 'npx --yes flatspace@latest build' without requiring local node_modules.
