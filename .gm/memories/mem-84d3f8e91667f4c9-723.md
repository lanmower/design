anentrypoint-design: a component that returns a BARE element on one branch and a wrapped element on another must carry the callers `key` on whichever node it actually returns. An internal key like key:"i" only needs to be unique among that components own children; when the element is returned unwrapped it becomes the node the caller keys. Select() in src/components/content/fields.js hardcoded key:"i" and dropped the caller key on its no-label/no-hint/md branch, so two sibling label-less Selects both keyed as "i" and webjsx collapsed them -- measured two selects before a re-render, ONE after, the survivor wearing the wrong accessible name. That is why workspace could not render agent and model pickers side by side.
