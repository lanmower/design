gm browser verb viewport prefix: body line viewport=<W>x<H>@<scale> drives CDP Emulation.setDeviceMetricsOverride and renders at any width independent of the host screen and OS window size (verified 1920 and 2560 on a 1536px screen). The @<scale> suffix is REQUIRED for desktop: without it mobile defaults true (cdp_eval.js uses viewport.mobile !== false) and Emulation.setTouchEmulationEnabled fires, so pointer:coarse matches true and hover:hover false, silently corrupting touch-target and hover measurements. The token !mobile does NOT work. A comma separator breaks prefix parsing and the dispatch is rejected with code required. Prefixes stack with timeout= and url=.
