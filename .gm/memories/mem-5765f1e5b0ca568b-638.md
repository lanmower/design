247420/portfolio GitHub Pages deploy: requires BOTH build_type=workflow AND a branch-protection policy. Set via gh api repos/OWNER/REPO/pages -X POST/PUT -f build_type=workflow. If the github-pages environment has protection_rules with custom_branch_policies, you MUST add the deploying branch via gh api repos/OWNER/REPO/environments/github-pages/deployment-branch-policies -X POST -f name=main -f type=branch — else the deploy job fails 'Branch X is not allowed to deploy to github-pages due to environment protection rules'. Non-obvious because the error only surfaces at deploy time and the endpoint is not discoverable from the UI.
