anentrypoint-design: `busy` and `loading` are two different states, not two spellings of one, and must never be converged. `loading` = a DATA FETCH is in flight and owns which SHAPE renders (skeleton when cold, dimmed rows when refreshing). `busy` = a USER ACTION is in flight and owns INTERACTIVITY (disable controls so a second click cannot re-fire the mutation). They are orthogonal and co-occur: FileGrid takes BOTH deliberately -- its `loading` picks skeleton-vs-dim while its `busy` is forwarded per-row to disable open/rename/delete. Passing one where the other belongs is a real bug. Related: the empty slot has nothing to converge either -- `emptyText` (a string) is the ONLY empty-slot PROP; `emptyState` is a page-level helper FUNCTION exported from components/freddie/runtime.js, never a prop. A regex that counts emptyState call sites as prop uses will wrongly report a naming split.
