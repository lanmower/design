247420 design SDK: decorative unicode glyphs are BANNED in source (machine-shaped tell). The canonical fix is the Icon(name,{size}) line-icon SVG component in src/components/shell.js (extend ICON_PATHS to add names; an out-of-set name renders an EMPTY span = bug). Status dots render as CSS circles via <span class="ds-dot ds-dot-on|ds-dot-off"> (Dot() component, .ds-dot in app-shell.css), NOT text glyphs. ASCII stands in where no icon fits (-> for arrows, [x] for checks, - for bullets). Exempt: middle-dot separator and the Mac Command key symbol. A build-time guard scripts/lint-glyphs.mjs (wired into build.mjs alongside lint-tokens) fails the build on any banned glyph in src/ui_kits/slides/site — this is what stops the sweep regressing. <option> children are string-only (no SVG), so use words there.
