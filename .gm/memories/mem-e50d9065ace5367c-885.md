247420 design file-browser primitives caveats: file-type values are dir/image/video/audio/code/text/archive/document/symlink/other; anything else -> neutral rail + the fallback glyph. Rail COLOR comes from data-file-type on the row — NEVER hand-apply .rail-green/.rail-sun to file rows (CSS owns the mapping; doubling makes one rule silently lose). FileViewer portal-renders to <body> via Backdrop (z above topbar); set data-file-type on BOTH head AND body of the viewer or the inside falls back to neutral. DropZone only previews local-file UI — real upload needs preventDefault on document (not just the zone) or the browser navigates to the dropped file. UploadProgress reads data-pct on .ds-upload-fill (string 0-100, not a percent string). BreadcrumbPath calls onNav(0) for root and onNav(i+1) per segment — the index is 'how many segments to keep', not 'which was clicked'.
