gm-method: verifying a CSS pointer:coarse touch-target media query via browser automation requires GENUINE touch emulation (CDP Emulation.setTouchEmulationEnabled + setEmitTouchEventsForMouse with maxTouchPoints>0), not just a narrow viewport resize -- a desktop Chromium instance at a 375px viewport still reports matchMedia('(pointer:coarse)').matches===false and pointer:fine===true, so measuring a touch-target element's height at a narrow viewport without touch emulation silently validates the WRONG code path (the fine-pointer CSS branch) and gives a false negative for a real touch-target bug, or a false positive that the media query 'must be broken' when it is actually correct. Always pair a coarse-pointer assertion (matchMedia read) with the size assertion in the same witness so the two can't drift apart unnoticed.
