gm-method: a live browser witness of a newly-added component sometimes reveals the REAL bug isn't in the new code at all -- it's in the host page's own stylesheet wiring (a showcase/demo kit missing a <link> to a stylesheet its own pre-existing components depend on). Diagnostic sequence that actually locates this: read document.styleSheets in-page to list what's ACTUALLY loaded (not what you assume from reading the HTML source), cross-reference against the CSS class the component needs, then grep every sibling page for the same missing-link pattern before fixing just the one you found -- a single showcase page silently missing a stylesheet link often means every OTHER demo component in that same page has been rendering unstyled since its own introduction, not just the newest addition.
