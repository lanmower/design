anentrypoint-design browser verb ABI (agentplug native build, 2026-07-29): the spool file CONTENT is evaluated directly. Two working shapes only -- a BARE JS body (no JSON wrapper) using return, or JSON {code, cwd?, sessionId?}. The key is code, NOT body/script/prompt: a JSON wrapper using any other key gets the whole JSON string evaluated as JS, producing the misleading "cdp-eval: exception SyntaxError: Unexpected token :" even for a trivial payload like 1+1 -- the colon is the JSON separator, not anything in your script. Also: this build has NO Playwright wrapper on the eval path, so page/page.evaluate/page.setViewportSize are all undefined (ReferenceError: page is not defined); code runs IN-PAGE, so use plain DOM and document/location directly. The documented prefix forms (timeout=, url=, dom=, screenshot=) are NOT parsed by this build -- a url= prefix is silently ignored and you keep measuring whatever page the persistent session already had loaded, which silently yields before-numbers when you think you are measuring after-numbers. Navigate with location.href= in one dispatch, then measure in a SEPARATE dispatch after a sleep. file:// is unreachable from an https:// session (cross-scheme navigation blocked) -- serve the artifact over http (npx http-server) and navigate to 127.0.0.1. Viewport is fixed by the CDP session: viewport/width/height keys are ignored and window.resizeTo cannot exceed screen.availWidth, so to measure wide-viewport behaviour set an explicit px width on .app-main and read the stage, then restore it.
