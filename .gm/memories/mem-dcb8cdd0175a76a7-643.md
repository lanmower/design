anentrypoint-design / webjsx: a null prop value renders the STRING "null", it does not omit the attribute. updateAttributesCore (vendor/webjsx/attributes.js, shared by both the initial setAttributes path and the updateAttributes path) stringifies it. So `id: id || null` emits id="null" (an invalid duplicate id on any page with more than one such component) and `href: isControl ? x : null` emits href="null" -- still a link, still tab-stopped, still pointer-cursored. The ONLY way to actually leave an attribute off is to spread the key in conditionally: ...(id ? { id } : {}). Found live in PageHeader/Panel/Section (4 sites) and in Side().
